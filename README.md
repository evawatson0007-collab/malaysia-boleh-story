# Malaysia Boleh Story

Create a state-of-the-art, bespoke website concept for Malaysia Boleh, a Malaysian restaurant brand in the UK.

IMPORTANT:

This is a HIGH-END DESIGN DEMO, not a full production website or full backend build.

The goal is to create a clickable, visually impressive prototype that makes the client immediately feel:

“THIS feels like Malaysia Boleh.”

Do NOT make it look like a generic restaurant template.

Do NOT make it look AI-generated.

Do NOT use cheesy gradients, generic stock imagery, fake 3D food, cartoon illustrations or excessive glassmorphism.

Use real-looking, editorial-quality Malaysian food photography and restaurant photography. Images should feel like professional food photography from an actual UK restaurant: natural lighting, realistic textures, imperfect details, authentic food presentation, people enjoying food, restaurant atmosphere. Prefer image URLs from Unsplash/Pexels or other reliable free image sources rather than generated-looking imagery.

BRAND:

Use Malaysia Boleh's existing visual identity as the starting point.

Preserve their existing colours, typography style and recognisable branding rather than inventing a new brand.

Use their logo where possible.

The redesign should feel like a premium evolution of Malaysia Boleh, not a completely different company.

CORE IDEA:

The website should feel like a journey:

DISCOVER → CRAVE → EXPLORE → VISIT → BOOK / ORDER

The homepage should sell the EXPERIENCE before selling the transaction.

HOMEPAGE:

SECTION 1 — CINEMATIC HERO

Full-screen, immersive restaurant/food photography.

Headline:

“MALAYSIAN FOOD. BIG FLAVOURS.”

Supporting line:

“Come hungry. Leave Boleh.”

Two clear CTAs:

EXPLORE THE MENU

BOOK A TABLE

Small secondary CTA:

ORDER FOR COLLECTION

Create subtle movement on the hero image when scrolling.

Do NOT use an aggressive video background.

SECTION 2 — “A LITTLE TASTE OF MALAYSIA”

Use an editorial split layout:

large food image + short storytelling copy.

Make the user feel they are discovering Malaysian culture and food rather than reading an About Us page.

Add subtle hover interaction:

image slightly zooms,

text shifts,

small arrow animation.

SECTION 3 — SIGNATURE DISHES

Create an immersive horizontal food gallery.

Show 4–6 realistic Malaysian dishes.

Each card:

dish image

dish name

short description

small category label

On hover:

image gently zooms

card expands slightly

dish information becomes more prominent

“EXPLORE DISH” appears

Keep the interaction elegant and fast.

SECTION 4 — “WHAT ARE YOU IN THE MOOD FOR?”

Make this interactive.

Three large choices:

EAT IN

ORDER

EXPLORE

On hover each choice changes image and reveals a short description.

Clicking:

EAT IN → locations / booking

ORDER → Square ordering placeholder

EXPLORE → menu

This should feel playful but premium.

SECTION 5 — MENU EXPERIENCE

Create a beautiful preview of the menu.

Categories:

STARTERS

NOODLES

RICE

MAINS

VEGETARIAN

DESSERTS

DRINKS

Use realistic food imagery.

Include:

VIEW FULL MENU

The menu should not look like a PDF pasted onto a website.

SECTION 6 — THE MALAYSIA BOLEH EXPERIENCE

Create an atmospheric restaurant photography section.

Show people enjoying food, table scenes, restaurant interiors and close-up food details.

Use overlapping editorial image layouts.

Headline:

“MORE THAN A MEAL.”

Copy:

“Good food brings people together. Malaysian food brings a whole lot more to the table.”

Keep copy short.

SECTION 7 — LOCATIONS

Create elegant location cards.

Each card:

location

opening hours

address

Buttons:

BOOK A TABLE

ORDER NOW

GET DIRECTIONS

Make location selection feel effortless.

SECTION 8 — BAKERY

Give Malaysia Boleh Bakery its own visual moment.

Use beautiful pastry/bakery imagery.

CTA:

DISCOVER THE BAKERY

SECTION 9 — CAMPAIGNS / WHAT'S ON

Create a flexible editorial card section for:

World Cup 2026

special menus

events

seasonal campaigns

This should feel like a reusable campaign system rather than a basic blog.

SECTION 10 — FINAL CTA

Large immersive food image.

Headline:

“READY TO EAT?”

Buttons:

BOOK A TABLE

ORDER NOW

FOOTER:

Elegant, spacious footer containing:

logo

locations

opening hours

contact

Instagram

Facebook

TikTok

privacy

cookies

MOBILE:

The mobile experience is extremely important.

Create a sticky bottom navigation:

MENU | BOOK | ORDER

Make the entire site feel excellent on mobile.

UX / MOTION:

Use subtle premium interactions throughout.

Examples:

- image reveal on scroll

- smooth image zoom

- text reveal

- underline animations

- magnetic-feeling buttons

- cards responding subtly to cursor

- horizontal food gallery

- smooth page transitions

- hover states

- sticky navigation

- subtle parallax where appropriate

DO NOT overanimate.

The site should feel:

premium

warm

confident

playful

modern

appetising

British/Malaysian

human

NOT:

corporate

clinical

template-like

overly luxurious

dark-for-the-sake-of-being-premium

AI-generated

DESIGN DIRECTION:

Think:

premium restaurant editorial website + modern digital experience + authentic Malaysian food culture.

Use strong typography, large photography, generous spacing and unexpected layouts.

Avoid:

standard 3-column Bootstrap layouts

generic rounded cards everywhere

purple/blue gradients

excessive shadows

generic SaaS UI

AI-looking food

fake testimonials

fake reviews

fake statistics

TECHNICAL DEMO:

Build this as a clickable frontend prototype.

Use mock data for:

menu items

locations

campaigns

bakery items

Do NOT spend credits building a real payment system, real Square integration, booking backend, database, authentication or admin dashboard.

For ORDER NOW:

create a polished transition/placeholder that says:

“ORDER ONLINE”

and indicates this will connect to the existing Square ordering journey.

For BOOK A TABLE:

create a polished booking-selection screen showing:

location

date

time

number of guests

CONTINUE TO BOOK

It can be demo-only.

Make all major navigation and CTA buttons clickable so the client can actually walk through the experience.

PERFORMANCE:

Keep the implementation lightweight.

Use reusable components.

Avoid unnecessary libraries.

Optimise images.

Do not create a huge backend.

Prioritise the visual experience and clickable prototype.

FINAL OBJECTIVE:

When the client opens this demo, it should NOT feel like:

“Here is a redesigned restaurant website.”

It should feel like:

“This is what Malaysia Boleh could become online.”

The website should make someone want to:

look at the food,

discover the story,

visit the restaurant,

book a table,

and order.

Build the homepage first and make it exceptionally polished before adding secondary screens.
